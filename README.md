## 02 - Countdown Timer

A simple command-line countdown timer built in Python.

### Features
- Takes user input in seconds
- Counts down and displays time in `HH:MM:SS` format
- Alerts when time's up

### Tech Stack
- Python

### How to Run
1. Navigate to the `02-Countdown-Timer` folder
2. Run the script:
```bash
   python timer.py
```
3. Enter the number of seconds when prompted
